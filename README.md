# us-er0.github.io

「能量增量」—— 一个用 Canvas 实现的增量游戏（incremental game），通过升级发电节点持续积累焦耳能量。

在线地址：https://us-er0.github.io

## 玩法

- **获取能量**：每帧自动产出 `每秒产能 × 经过时间`；点击画布空白处也可手动 +1 能量。
- **升级节点**：点击节点方块消耗能量提升等级。节点有前置解锁条件，满足后自动点亮。
- **拖动画布**：按住空白处拖动可平移整个节点网络。

## 升级体系

| # | 节点 | 效果 | 前置 |
|---|------|------|------|
| 1 | 太阳 | 每秒获取 1 基础能量 | 无 |
| 2 | 叶绿体 | 太阳产出 × 当前等级平方 | 太阳 ≥1 级 |
| 3 | 储能电池 | 全局能量获取倍率 +0.5/级 | 叶绿体 ≥1 级 |
| 4 | 光能阵列 | 基础太阳产能 +3/级 | 储能电池 ≥2 级 |
| 5 | 聚光镜 | 光能阵列效果翻倍/级 | 光能阵列 ≥3 级 |

每秒产能公式：

```
每秒产能 = (1 + 光能阵列等级×3×2^聚光镜等级) × 太阳等级 × (叶绿体等级+1)² × (1 + 电池等级×0.5)
```

## 文件结构

```
index.html        入口页面
decimal.js        大数运算库（Decimal）
data.js           游戏数据与升级定义
calculator.js     产能计算
canvasControl.js  画布绘制
misc.js           工具函数（画布自适应、碰撞检测）
init.js           主循环与鼠标交互
```

## 技术说明

- 纯原生 JS + Canvas 2D，无任何框架依赖
- 使用 `decimal.js` 处理超大数值
- `requestAnimationFrame` 驱动主循环，按 `dt` 增量累加，与帧率无关

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建或服务器。
